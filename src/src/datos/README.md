# src/datos: carga y tipos del grafo, los lugares y el plano (sin React).

- `tipos.ts`: formato de `public/data/grafo.json` (`GrafoCampus`), `lugares.json` (`CatalogoLugares`) y `plano.json` (`PlanoBase`).
- `config.ts`: `METROS_POR_PX` (de `datos-fuente/config.json`), y URLs de los datos.
- Se importa todo desde `src/datos/index.ts`.
